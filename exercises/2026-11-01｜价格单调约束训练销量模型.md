## 1. 任务背景

普通神经网络只拟合历史样本，可能学出不符合业务常识的局部关系：在促销、周末和近期销量保持不变时，提高商品价格，预测销量反而上升。

今天你将为一个 PyTorch 销量回归模型加入价格单调约束：

1. 为每个真实样本构造“只提高价格”的反事实样本；
2. 分别预测原价格与更高价格下的销量；
3. 对“涨价后预测销量上升”的部分施加惩罚；
4. 将监督回归损失与单调惩罚组合训练；
5. 评估涨价反事实下的单调违反率和平均违反幅度。

约定在其他输入完全相同时：

[
hat{y}(price 	imes (1+r)) leq hat{y}(price)
]

本练习关注软约束训练，不要求网络结构从数学上绝对单调。预计完成时间为 20–30 分钟。

## 4. 待完成任务

1. 实现 `SalesModel.forward`：
   - 执行 `hidden -> ReLU -> output -> Softplus`。
   - 输出必须为二维张量 `[batch_size, 1]`。
   - Softplus 用于保证预测销量非负，不能对中间隐藏层使用它替代 ReLU。

2. 实现 `validate_training_data`：
   - `x` 必须为二维浮点 Tensor，`y` 必须为 `[N, 1]` 浮点 Tensor。
   - 两者样本数一致、非空且所有元素有限。
   - `price_index` 必须指向有效特征列。
   - 价格严格大于 0，目标销量不得为负。
   - 函数不得原地修改输入。

3. 实现 `make_higher_price_inputs`：
   - `increase_rate` 必须为有限的正数。
   - 先复制输入，再只修改价格列。
   - 新价格严格等于原价格乘以 `1 + increase_rate`。
   - 其他特征逐元素保持不变。
   - 调用后原始 `x` 必须完全不变。

4. 实现 `monotonicity_penalty`：
   - 原始输入与反事实输入都经过同一个模型。
   - 只惩罚 `pred_higher_price > pred_original` 的部分。
   - 返回零维标量 Tensor。
   - 禁止使用 `.item()`、`detach()` 或 `torch.no_grad()`，确保惩罚可反向传播。
   - 不得把模型预测按大小排序后再比较。

5. 实现 `train_one_epoch`：
   - 每个批次依次执行清梯度、前向、组合损失、反向传播和参数更新。
   - `total_loss = regression_loss + penalty_weight * penalty`。
   - 三项 epoch 指标都按批次样本数加权，不得直接平均批次均值。
   - 累计日志时应脱离计算图。
   - `penalty_weight=0` 时退化为普通监督训练。
   - 训练循环中的关键步骤必须由学习者完成。

6. 实现 `evaluate_monotonicity`：
   - 使用 `torch.no_grad()` 环境。
   - 违反率分母为全部样本数。
   - 只有违反幅度严格大于 `tolerance` 才计为违反。
   - 三项结果均返回有限的 Python `float`。
   - 调用前若模型处于训练模式，函数结束后仍应处于训练模式；评估模式同理。

7. 完成以下自检：
   - 反事实输入中只有价格列发生变化。
   - `monotonicity_penalty(...).requires_grad` 为 `True`。
   - 惩罚反向传播后，至少一个模型参数获得非空梯度。
   - 分别从相同初始权重训练 `penalty_weight=0` 与 `penalty_weight=5` 的模型，比较回归误差和违反率。
   - 尝试 `increase_rate=0.05`、`0.10`、`0.20`，观察约束评估是否一致。
