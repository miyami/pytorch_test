## 1. 任务背景

商品当天卖出 20 件且闭店时库存为 0，并不代表真实需求恰好是 20。顾客可能在缺货后继续到店但无法购买，因此缺货日的观测销量只是需求下界。

如果直接把所有观测销量都作为精确标签使用 MSE，模型会把被库存截断的销量当成真实需求，容易系统性低估旺销商品。

今天你将实现一个缺货感知的 PyTorch 损失：

- 非缺货样本：观测销量可视为完整标签，使用 Smooth L1 Loss；
- 缺货样本：只知道真实需求不低于观测销量，仅当预测低于观测销量时施加单侧平方惩罚；
- 训练后分别评估非缺货样本 MAE，以及缺货样本的下界违反率和平均缺口。

本练习不估计缺货后的真实需求，只正确表达标签的“精确值”与“下界”差异。预计完成时间为 20–30 分钟。

## 4. 待完成任务

1. 实现 `DemandModel.forward`：
   - 执行 `hidden -> ReLU -> output -> Softplus`。
   - 输出必须为二维张量 `[batch_size, 1]`。
   - Softplus 用于保证需求预测非负。

2. 实现 `validate_censored_data`：
   - `x` 必须为二维浮点 Tensor。
   - `sales` 必须为 `[N, 1]` 浮点 Tensor。
   - `stockout_mask` 必须为同形状的布尔 Tensor。
   - 三者样本数一致、非空，数值均有限，销量不得为负。
   - 必须同时存在至少一个缺货样本和一个非缺货样本。
   - 不得原地修改输入。

3. 实现 `censored_sales_loss`：
   - 三个 Tensor 的 shape 必须完全一致。
   - `stockout_weight` 必须是有限的非负数。
   - 非缺货样本使用逐元素 Smooth L1 Loss。
   - 缺货样本仅在预测低于观测销量时产生平方惩罚。
   - 使用 `torch.where` 合并两类逐样本损失后取平均。
   - 返回零维 Tensor，禁止调用 `.item()` 或 `detach()`。
   - 关键损失构造逻辑由学习者完成。

4. 实现 `train_one_epoch`：

   - epoch 平均损失按样本数加权。
   - 日志累计时脱离计算图。
   - `updated_samples` 必须等于本轮实际训练样本数。

5. 实现 `evaluate_censoring_behavior`：

   - 违反率分母只能是缺货样本数。
