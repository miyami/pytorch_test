# 2026-10-22｜Item2Vec负采样训练商品向量

## 1. 任务背景

在商品推荐中，可以把同一用户按时间排序的交互商品看作一句“商品序列”，把相邻出现的商品视为具有上下文关系。Item2Vec 使用与 Skip-gram 类似的训练目标：给定中心商品，提高真实上下文商品的相似度，同时降低随机负样本商品的相似度。

今天你将使用几条小型购物序列完成一个最小 Item2Vec 训练闭环：

1. 用滑动窗口构造“中心商品—上下文商品”正样本；
2. 按商品出现频次的 (0.75) 次幂生成负采样分布；
3. 为每条正样本采样多个负商品，并排除真实上下文；
4. 用两套 Embedding 计算正、负样本点积；
5. 实现负采样损失并更新商品向量；
6. 根据余弦相似度查看相近商品。

本练习不复用近期的销量分位数、预测区间或时间序列评估方式，数据也改为用户商品序列。预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `build_skipgram_pairs`：
   - `window_size` 必须是正整数。
   - 每个序列长度至少为 2；所有商品索引必须是非负整数。
   - 对每个中心位置，选取左右不超过 `window_size` 的有效上下文位置。
   - 只能排除中心“位置”，不能按商品 ID 排除相同商品。
   - `centers` 与 `contexts` 长度相同，且都为一维 `torch.long` Tensor。

2. 实现 `build_negative_distribution`：
   - `num_items` 必须为正整数，`power` 必须为有限正数。
   - 用全部序列的出现次数计算分布。
   - 未出现商品的采样概率应为 0。
   - 输出必须非负、有限且总和接近 1。
   - 不能手工写死每个商品的概率。

3. 实现 `sample_negative_items`：
   - `distribution` 必须是一维概率 Tensor。
   - `positive_contexts` 必须是一维 `torch.long` Tensor。
   - `num_negatives` 必须是正整数。
   - 每行的负样本都不能等于对应的真实上下文。
   - 只重采样冲突位置，不得改为均匀采样。
   - 使用传入的 `generator` 保证结果可复现。

4. 实现 `Item2Vec.forward`：
   - 中心和正上下文 shape 必须相同。
   - 负样本第一维必须与 batch size 一致。
   - 正样本点积输出 shape 为 `[B]`。
   - 负样本点积输出 shape 为 `[B, K]`。
   - 使用批量 Tensor 运算，不得逐样本循环。

5. 实现 `negative_sampling_loss`：
   - 正 logits 为一维，负 logits 为二维。
   - 两者 batch size 必须相同。
   - 必须使用 `F.logsigmoid`，不能先计算 sigmoid 再取 log。
   - 返回有限、非负、保留梯度的零维 Tensor。

6. 实现 `train_one_step`：
   - 严格执行清空梯度、负采样、前向、计算损失、反向传播、更新参数。
   - 返回值必须是 Python `float`。
   - 不得在训练中使用 `detach` 阻断损失梯度。

7. 实现 `most_similar_items`：
   - 查询商品必须存在于词表。
   - `topk` 不得超过“商品总数减 1”。
   - 对向量做 L2 归一化后计算余弦相似度。
   - 结果按相似度从高到低排序，且不能包含查询商品自身。
   - 返回商品名和 Python `float` 相似度。

8. 添加断言完成自检：
   - 当前数据在 `window_size=2` 时应生成非空正样本。
   - 所有中心和上下文索引都应位于 `[0, len(ITEMS))`。
   - 负采样分布之和应接近 1。
   - 固定随机种子时，两次负采样结果应一致。
   - 任意负样本都不能等于对应真实上下文。
   - 模型输出 shape 必须分别为 `[B]` 和 `[B, K]`。
   - 损失必须有限，且训练后至少有一个 Embedding 参数发生变化。
   - 近邻结果数量为 3，且不包含“牛奶”。
