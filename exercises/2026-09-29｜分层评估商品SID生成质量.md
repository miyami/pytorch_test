# 2026-09-29｜分层评估商品SID生成质量

## 1. 任务背景

昨天你完成了商品 Semantic ID（SID）生成模型的 Teacher Forcing 训练。训练损失下降或逐 token 准确率较高，并不等于模型已经能准确召回商品：一个三层 SID 只要有一层预测错误，完整商品就可能无法命中；模型还可能生成商品目录中不存在的 SID。

今天不再重复模型训练和解码，而是实现一组**序列级评估指标**：

- Token Accuracy：每层 token 的整体正确率；
- Exact Match Rate：完整 SID 全部正确的样本比例；
- Prefix Accuracy@Level：前 (L) 层全部正确的样本比例；
- Valid SID Rate：预测 SID 存在于商品目录中的比例；
- First Error Level：首次发生错误的位置分布。

这些指标可以帮助你区分“局部 token 学得不错”和“最终商品真正召回成功”。

预计完成时间：20–30 分钟。
