# 2026-09-26｜前缀树约束商品SID解码

## 1. 任务背景

昨天你把商品向量量化成了多级 Semantic ID（SID）。下一步是让生成模型根据用户行为生成目标商品的 SID。

问题在于：模型对整个 Token 词表输出分数，如果每一步都直接取最高分，可能得到目录中不存在的组合。例如，商品目录只有 `[1, 5]` 和 `[1, 6]`，模型却可能生成 `[1, 7]`。

今天你要实现**基于前缀树（Trie）的受约束解码**：

1. 把所有有效商品 SID 加入前缀树；
2. 根据当前已生成前缀，查询下一步允许出现的 Token；
3. 将非法 Token 的 logit 设为 `-inf`；
4. 在合法 Token 中选择最高分；
5. 生成 `EOS` 后停止，并映射回商品 ID。

本题不重复残差量化，也不训练生成模型。重点是理解 SID 生成后如何通过目录约束保证召回结果一定有效，预计 20–30 分钟完成。
