# 2026-10-25｜计划采样训练多步销量GRU

## 1. 任务背景

多步销量预测常见两种训练方式：

- Teacher Forcing：解码下一步时输入上一时刻的真实销量，训练稳定，但推理时拿不到未来真实值；
- 自回归预测：把模型上一时刻的预测作为下一步输入，训练与推理一致，但早期误差容易连续放大。

今天你将实现“计划采样（Scheduled Sampling）”：训练初期主要使用真实值，随后逐步降低 Teacher Forcing 比例，使模型逐渐适应自己的预测结果。最终验证时必须完全自由运行，不能读取任何未来真实销量。

本练习直接提供成对的历史与未来销量 Tensor，不复用近期的时间补丁、滑窗构造、分位数损失或召回向量套路。预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `validate_sequences`：
   - `history` 必须是非空二维浮点 Tensor，布局为 `[B, T]`。
   - `horizon` 必须是正整数。
   - 所有销量必须有限且非负。
   - 当 `future` 不为 `None` 时，它必须与历史位于同一 device，shape 为 `[B, horizon]`。
   - 不得原地修改输入。

2. 实现 `linear_teacher_forcing_ratio`：
   - `num_epochs >= 2`，`epoch` 位于 `[0, num_epochs - 1]`。
   - 起止比例必须是有限数且位于 `[0, 1]`。
   - 使用 `epoch / (num_epochs - 1)` 计算插值进度。
   - 首轮必须精确返回起始比例，末轮必须精确返回结束比例。
   - 返回 Python `float`。

3. 实现 `ScheduledSamplingGRU.forward`：
   - 编码器输入 shape 应为 `[B, T, 1]`。
   - 解码器隐藏状态 shape 应为 `[B, hidden_size]`。
   - 每轮产生一个 `[B, 1]` 预测，并作为候选下一步输入。
   - 当 `future is not None` 时，为每个样本独立生成 `[B, 1]` 随机选择掩码。
   - 掩码为真时使用 `future[:, step]`，否则使用当前预测。
   - 当 `future is None` 时，即使比例非零也不得读取真实未来值。
   - 不得一次性把未来标签输入解码器。
   - 最终输出必须为 `[B, horizon]`。

4. 实现 `train_one_epoch`：
   - `teacher_forcing_ratio` 必须位于 `[0, 1]`。
   - 严格执行训练模式、清空梯度、前向、损失、反向传播、裁剪和参数更新。
   - 均方误差必须在所有样本和所有预测步长上取平均。
   - `max_grad_norm` 必须是有限正数。
   - 返回 `{"loss": ..., "grad_norm": ...}`，值均为 Python `float`。

5. 正确处理随机性：
   - 计划采样只能使用传入的 `generator`。
   - 固定模型参数与 generator 状态时，随机选择应可复现。
   - `teacher_forcing_ratio=1.0` 时，训练中下一步输入必须全部来自真实值。
   - `teacher_forcing_ratio=0.0` 时，训练和推理都必须完全自回归。

6. 添加断言完成自检：
   - 比例序列首项为 1、末项为 0，并且单调不增。
   - 模型输出 shape 为 `[batch_size, 3]`。
   - Teacher Forcing 比例为 0 且模型参数不变时，传入不同 `future` 不应改变预测。
   - 推理时 `future=None` 能正常运行。
   - 所有训练损失、梯度范数和模型参数必须有限。
   - 至少一个模型参数在训练后发生变化。
   - 验证集预测必须有限，且不得为负数时可思考是否需要额外输出约束。
   - 整体 MAE 应等于三个 horizon MAE 的平均值。
