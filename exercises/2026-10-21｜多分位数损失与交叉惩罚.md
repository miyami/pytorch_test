# 2026-10-21｜多分位数损失与交叉惩罚

## 1. 任务背景

昨天你使用 Split Conformal Prediction，在模型训练完成后根据校准残差构造销量预测区间。今天换一种思路：让神经网络直接预测销量分布的多个条件分位数。

你需要让模型同时输出 (q=0.1、0.5、0.9) 三个分位数，分别代表偏低、中位和偏高的销量预测。训练时使用 Pinball Loss；同时加入“分位数交叉惩罚”，减少 (Q_{0.1} > Q_{0.5}) 或 (Q_{0.5} > Q_{0.9}) 这类不合理结果。

本练习使用表格特征，不复用近期的时间补丁、逐步长评估或校准残差构造方式。预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `standardize_from_train`：
   - 两个输入都必须是二维浮点 Tensor，且特征数相同。
   - 均值和标准差只能来自 `train_features`。
   - 统计量沿样本维计算，并保持可广播形状。
   - 对标准差为 0 的特征使用 1 作为除数。
   - 不得原地修改输入。

2. 实现 `QuantileSalesNet.forward`：
   - 输入必须是 shape `[N, F]` 的二维 Tensor。
   - 依次通过 `backbone` 和 `head`。
   - 输出 shape 必须为 `[N, Q]`。
   - 不要在输出层使用排序、`softmax` 或不可导的修复操作。

3. 实现 `pinball_loss`：
   - `prediction` 为 `[N, Q]`，`actual` 为 `[N]`。
   - `quantiles` 长度必须为 `Q`，严格递增，且每个值位于 `(0, 1)`。
   - 按给定公式同时计算所有样本和所有分位数的损失。
   - 返回零维标量 Tensor，并保留梯度。
   - 不能用 Python 循环逐分位数计算。

4. 实现 `quantile_crossing_penalty`：
   - 比较所有相邻分位数列。
   - 未发生交叉的位置贡献 0。
   - 交叉越严重，惩罚越大。
   - 返回可参与反向传播的零维标量 Tensor。
   - 当所有分位数顺序正确时，惩罚必须严格为 0。

5. 实现 `quantile_crossing_rate`：
   - 一个样本只要存在任意相邻分位数交叉，就记为交叉样本。
   - 返回交叉样本数占总样本数的比例。
   - 该函数用于评估，不参与训练损失。

6. 实现 `train_one_epoch`：
   - 总损失为
     `pinball + penalty_weight * crossing_penalty`。
   - `penalty_weight` 必须是有限且非负的数。
   - 严格执行清空梯度、前向、计算损失、反向传播、更新参数。
   - 返回的字典必须含 `total`、`pinball` 和 `crossing_penalty`。
