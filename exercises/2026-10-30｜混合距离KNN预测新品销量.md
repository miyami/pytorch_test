## 1. 任务背景

新品没有历史销量，无法直接构造滞后销量、移动平均等时序特征。一个可解释的冷启动基线是：从已有商品中找到属性相近的商品，用其销量加权估计新品销量。

今天你将实现一个混合距离 KNN 回归器：

1. 仅用已有商品拟合数值特征的标准化参数；
2. 将标准化后的数值距离与品牌不一致惩罚相加；
3. 先在同品类商品中选择最近邻；
4. 使用反距离权重预测新品周均销量；
5. 处理完全相同属性、同品类无候选等边界情况；
6. 用留一法评估该冷启动基线的 MAE。

本练习使用商品属性表，不复用近期的序列模型、召回解码、梯度监控或节假日特征构造套路。预计完成时间为 20–30 分钟。

1. 实现 `validate_product_tables`：
   - 两张表必须包含 `item_id`、`category`、`brand` 和全部数值特征。
   - 参考表还必须包含 `avg_weekly_sales`。
   - 每张表内部的 `item_id` 必须非空且唯一，两张表的商品 ID 不得重叠。
   - 类别与品牌不得为空；数值特征必须有限且大于 0。
   - 历史销量必须有限且非负。
   - 不得原地修改输入 DataFrame。

2. 实现 `fit_numeric_scaler`：
   - 只能使用参考商品，不能拼接新品后再计算统计量。
   - 使用总体标准差 `ddof=0`。
   - 零标准差替换为 1.0。
   - 返回值索引顺序与 `NUMERIC_COLS` 完全一致。

3. 实现 `compute_mixed_distances`：
   - 对 query 和 candidates 使用同一组 `means`、`stds`。
   - 数值部分为逐候选欧氏距离。
   - 品牌不同增加一次 `brand_penalty`，品牌相同不增加。
   - `avg_weekly_sales` 不得参与距离。
   - 输入为空时返回同索引的空浮点 Series。
   - 不得修改 query、candidates、means 或 stds。

4. 实现 `inverse_distance_prediction`：
   - 两个数组必须是一维、等长且非空。
   - 销量与距离必须有限，且均不得为负。
   - 如果有一个或多个零距离候选，只平均这些候选的销量。
   - 没有零距离时使用归一化反距离权重。
   - 返回有限的 Python `float`。

5. 实现 `predict_one_product`：
   - 只使用同品类参考商品。
   - 按距离升序、商品 ID 升序进行确定性排序。
   - 候选不足 `k` 个时使用全部候选。
   - 同品类无候选时使用全局销量中位数，且近邻列表为空。
   - `N003` 应触发 `global_median`；其余新品应使用 `knn`。
   - 返回的近邻 ID 与距离顺序必须一致。

6. 实现 `predict_new_products`：
   - 只拟合一次全量参考商品 scaler。
   - 按新品表原始行顺序返回结果。
   - 不得把一个新品的预测结果写回并影响下一个新品。

7. 实现 `leave_one_out_mae`：
   - 每一折从参考表中移除当前商品。
   - 每折重新拟合 scaler，不能复用全量参考表统计量。
   - 被留出的商品只能作为 query，不能成为自己的近邻。

   - 确认结果为有限且非负的 Python `float`。
