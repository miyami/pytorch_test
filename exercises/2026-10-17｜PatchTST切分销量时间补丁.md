# 2026-10-17｜PatchTST切分销量时间补丁

## 1. 任务背景

在长历史窗口上直接逐时间点建模，序列很长、计算量也较大。PatchTST 的核心思路之一，是把连续时间点切成若干个 patch，再把每个 patch 当作一个 token；同时，各变量先独立切片，暂不在 patch 构造阶段混合通道。

今天先不训练完整 PatchTST，而是完成模型输入管道中最容易出错的一段：

1. 对每个样本、每个销量通道沿时间维做实例归一化；
2. 必要时在序列右侧补值，使最后一个 patch 完整；
3. 使用 `torch.unfold` 将 `[B, L, C]` 转为 `[B, C, N, P]`；
4. 用线性层把长度为 `P` 的 patch 投影为 `d_model` 维 token；
5. 验证 patch 数量、通道独立性和归一化后的统计量。

预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `validate_series`：
   - 输入必须是三维浮点 Tensor，布局为 `[B, L, C]`。
   - 三个维度都必须大于 0。
   - 所有值必须有限且非负。
   - 不允许在校验函数中修改输入。

2. 实现 `instance_normalize`：
   - `eps` 必须是有限正数。
   - 沿时间维 `dim=1` 计算均值和标准差。
   - 标准差使用 `unbiased=False`。
   - `mean` 和 `std` 必须保留时间维，即 shape 为 `[B, 1, C]`。
   - 使用 `(series - mean) / (std + eps)`。
   - 不得跨样本或跨商品通道混合统计量。

3. 实现 `required_right_padding`：
   - 三个输入都必须是正整数。
   - 如果原长度小于 patch 长度，至少补到一个完整 patch。
   - 否则返回使最后一个窗口完整对齐的最小非负整数。
   - 当前参数 `L=10, P=4, S=3` 时，padding 应为 `0`。
   - 自测 `L=11, P=4, S=3` 时，padding 应为 `2`。

4. 实现 `pad_series_right`：
   - `padding_length` 必须是非负整数。
   - padding 为 0 时返回内容相同的 Tensor。
   - 只能沿时间维右侧补值，批次和通道维不能变化。
   - 新增位置复制各序列最后一个时间点，不能补固定的全局数值。

5. 实现 `extract_patches`：
   - 先将 `[B, L, C]` 转为 `[B, C, L]`。
   - 在最后的时间维调用 `unfold(dimension=2, size=P, step=S)`。
   - 输出布局必须为 `[B, C, N, P]`。
   - patch 数量应满足
     `N = (L_padded - P) // S + 1`。
   - 保留重叠区域，不允许手动去重。

6. 实现 `PatchProjection.forward`：
   - 输入必须是四维 Tensor。
   - 最后一维必须等于线性层的 `in_features`。
   - 直接利用 `nn.Linear` 对最后一维投影，不写显式 batch 循环。
   - 输出前三个维度与输入一致，最后一维为 `D_MODEL`。

7. 用断言完成自检：
   - 当前数据的 `patches.shape` 应为 `(2, 3, 3, 4)`。
   - `tokens.shape` 应为 `(2, 3, 3, 8)`。
   - 归一化后每个样本、每个通道的时间均值应接近 `0`。
   - 非常数通道的总体标准差应接近 `1`。
   - 第 1 个 patch 应对应原序列时间位置 `0:4`。
   - 第 2 个 patch 应对应时间位置 `3:7`，与第 1 个 patch 重叠 1 个时间点。
   - 单独修改一个通道，只应影响该通道对应的 patch。
