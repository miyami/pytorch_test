# 2026-09-25｜残差量化生成商品语义ID

## 1. 任务背景

在传统向量召回中，每个商品由一个连续向量表示；在生成式召回中，常见做法是先把商品向量离散化成 Semantic ID（SID），再让序列模型直接生成商品对应的离散 Token 序列。

今天你不训练完整的 RQ-VAE，而是假设商品 Embedding 和两级码本都已经训练完成，只实现部署阶段的**残差量化编码**：

1. 第一级从码本中选择距离商品向量最近的向量；
2. 用商品向量减去第一级选中的码向量，得到残差；
3. 第二级继续量化残差；
4. 两级码向量相加得到重构向量；
5. 两级码字下标组成商品的 Semantic ID。

这能帮助你明确区分：

- **训练过程**：学习 Encoder、Decoder 和多级码本；
- **编码应用过程**：使用固定码本，把商品向量转换成 SID。

练习预计 20–30 分钟完成，关键距离计算、逐级残差更新和 SID 构造均由你编写。

   - 使用 `vectors[:, None, :]` 和 `codebook[None, :, :]` 完成广播。
   - 输出形状必须为 `[batch_size, num_codes]`。
   - 不允许逐商品、逐码字写双重 Python 循环。

2. 完成 `residual_quantize`：
   - 至少需要一个码本，所有码本的向量维度必须与输入一致。
   - 每一级都基于**当前残差**计算最近码字。
   - 使用 `argmin(dim=1)` 得到每个商品的码字索引。
   - 使用高级索引从码本中批量取出选中向量。
