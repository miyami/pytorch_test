# 2026-10-08｜评估零销量概率校准

## 1. 任务背景

昨天的零膨胀泊松模型会为每条样本输出“结构性零销量概率”。概率模型不能只看分类是否判断正确，还要检查概率值本身是否可信。

例如，模型对一批样本都给出约 `0.8` 的零销量概率，那么其中实际零销量的比例也应接近 `80%`。如果实际比例只有 `50%`，模型就存在过度自信。

今天你将手写三个评估组件：

- **Brier Score**：预测概率与二元标签之间的均方误差，越小越好。
- **分箱校准表**：比较每个概率区间内的平均预测概率与实际零销量率。
- **ECE（Expected Calibration Error）**：按样本数加权汇总各分箱的校准偏差，越小越好。

标签约定为：`1` 表示实际销量为零，`0` 表示实际销量大于零。练习只评估给定预测，不训练模型，重点放在概率校准逻辑和边界处理上。

预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `make_zero_labels`：
   - 拒绝非一维、空数组、包含非有限值或负数的销量。
   - 返回只包含 `0` 和 `1` 的整数数组。
   - 确认本题共有 7 个零销量标签。

2. 实现 `validate_probabilities`：
   - 概率和标签都必须是一维、非空且形状相同。
   - 概率必须有限并位于闭区间 `[0, 1]`。
   - 标签只能为 `0` 或 `1`。

3. 实现 `brier_score`：
   - 计算 `mean((probability - label) ** 2)`。
   - 返回 Python `float`，不要返回零维 NumPy 数组。

4. 实现 `build_calibration_table`：
   - `n_bins` 必须是正整数。
   - 使用 `np.linspace(0.0, 1.0, n_bins + 1)` 创建边界。
   - 每条样本只能进入一个分箱，概率恰好为 `1.0` 时必须进入最后一箱。
   - 主动编写逐箱循环，计算样本数、平均预测概率、实际零销量率和绝对偏差。
   - 空分箱仍需保留一条记录，其三个统计值填写 `np.nan`。

5. 实现 `expected_calibration_error`：
   - 校验 `total_count` 为正整数。
   - 忽略空分箱。
   - 使用原始样本数作为权重，不能对“各分箱偏差”直接做简单平均。

6. 实现 `evaluate_model`：
   - 返回键名为 `brier`、`ece`、`calibration_table` 的字典。
   - 不要在函数内部打印结果或修改输入数组。

7. 用断言完成自检：
   - 两个模型的 Brier Score 和 ECE 都应位于 `[0, 1]`。
   - 每张校准表长度应等于 `N_BINS`，所有 `count` 之和应等于样本数。
   - 对完全正确的概率 `labels.astype(float)`，Brier Score 和 ECE 都应为 `0.0`。
   - 额外加入概率 `0.0` 和 `1.0`，确认它们分别进入第一箱和最后一箱。
   - 额外传入 `-0.1`、`1.1` 或 `NaN`，确认校验会抛出 `ValueError`。
