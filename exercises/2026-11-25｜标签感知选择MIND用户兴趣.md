## 1. 任务背景

昨天的练习通过动态路由把用户历史拆成了多个兴趣向量，但训练时还有一个关键问题：一条点击样本应该用哪个兴趣与目标商品匹配？

MIND 使用标签感知注意力（Label-aware Attention）：目标商品与每个兴趣计算相关性，再按相关性软选择当前样本最相关的兴趣。温度越低，选择越接近硬路由；温度较高时，多个兴趣都能获得梯度。本练习使用预生成的多兴趣张量，聚焦标签感知选择、显式负样本对比损失与梯度检查，不重复昨天的动态路由实现。

预计用时：20–30 分钟。

## 4. 待完成任务

1. 实现 `label_aware_select`：
   - 批量计算目标商品与 `K` 个兴趣的点积；
   - 校验温度严格大于 0；
   - 在兴趣维上应用温度缩放 softmax；
   - 对兴趣向量加权求和，返回选择后的用户表示、权重和原始匹配分数。

2. 实现 `sampled_contrastive_loss`：
   - 分别计算正样本和每个负样本的匹配得分；
   - 将正样本放在 logits 第 0 列；
   - 使用温度缩放 logits；
   - 构造全 0 类别标签并计算交叉熵；
   - 不得在损失前对 logits 做 softmax。

3. 实现 `MINDTrainingHead.forward`：
   - 先使用正样本商品做标签感知兴趣选择；
   - 再用选择后的兴趣计算显式负样本对比损失；
   - 返回标量损失、兴趣权重和候选 logits。

4. 完成梯度与温度检查：
   - 不使用 `argmax`、`detach` 或 Python 索引硬选兴趣；
   - 保证每个样本至少有两个兴趣收到非零梯度；
   - 验证低温度权重熵不高于高温度权重熵；
   - 所有输出和梯度必须为有限值。

5. 观察 `logits.argmax(dim=1)`：
   - 第 0 列代表正样本；
   - 记录随机初始化的向量批次中有多少行把正样本排在首位；
   - 不要通过交换列或读取标签后修改 logits 来提高结果。
