# 2026-10-24｜分块TopK召回与候选合并

## 1. 任务背景

昨天你训练了双塔模型，并通过用户向量与商品向量的相似度完成召回。但真实商品库可能有几十万甚至上百万个商品，如果直接构造 `[用户数, 商品数]` 的完整分数矩阵，显存和内存很容易不足。

今天你将实现一个“精确但分块”的 Top‑K 召回器：

1. 将商品向量按固定大小分块；
2. 每次只计算当前商品块的相似度；
3. 过滤用户已经交互过的商品；
4. 将当前块候选与历史候选合并；
5. 始终只保留每个用户分数最高的 K 个商品；
6. 与全量矩阵结果比较，验证分块计算没有损失召回精度。

本练习不训练模型，也不复用昨天的批内负样本和交叉熵；核心是流式候选合并、索引映射和内存控制。预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `validate_retrieval_inputs`：
   - 用户向量与商品向量必须是非空二维浮点 Tensor。
   - 两者向量维度必须相同，且所有值有限。
   - `item_ids` 必须是一维 `torch.long` Tensor，长度等于商品数且值唯一。
   - `seen_mask` 必须是 bool Tensor，shape 为 `[num_users, num_items]`。
   - 所有 Tensor 必须位于同一 device。

2. 实现 `stable_topk`：
   - `scores` 与 `item_positions` shape 必须相同。
   - `k` 必须位于 `[1, num_candidates]`。
   - 首先按商品全局位置升序整理候选。
   - 再使用稳定排序按分数降序排列。
   - 分数相同时，较小的商品位置必须排在前面。
   - 不得逐用户写 Python 排序循环。

3. 实现 `full_matrix_topk`：
   - 先调用输入校验函数。
   - 沿最后一维对用户、商品向量做 L2 归一化。
   - 使用一次矩阵乘法计算余弦相似度。
   - 已交互商品分数必须替换为负无穷。
   - 使用 `stable_topk` 返回全量精确结果。

4. 实现 `chunked_topk`：
   - 不能创建完整 `[num_users, num_items]` 分数矩阵。
   - 每个商品必须被处理一次，最后一个不足整块的区间也不能遗漏。
   - 当前块的局部列必须映射为正确的全局商品位置。
   - 已交互过滤只能使用当前块对应的 mask 切片。
   - 每轮合并后候选数最多保留 K。
   - 返回结果必须与 `chunk_size` 无关。

5. 实现 `positions_to_item_ids`：
   - 所有位置必须是合法整数索引。
   - 使用 Tensor 索引一次完成转换。
   - 输出 shape 与 `positions` 完全相同。

6. 实现 `recall_at_k`：
   - 推荐结果必须为二维，目标商品必须为一维。
   - 两者用户数必须相同。
   - 每个用户只要任一推荐位置命中目标商品，就记为 1。
   - 返回位于 `[0, 1]` 的 Python `float`。

7. 添加断言完成自检：
   - 全量与分块结果的商品位置必须完全一致。
   - 对应分数必须在容差范围内一致。
   - 分别使用 `chunk_size=1、3、4、7、12`，结果都应相同。
   - 推荐位置不能命中 `seen_mask=True` 的商品。
   - 输出位置 shape 和商品 ID shape 都应为 `[4, 3]`。
   - `Recall@3` 必须有限且位于 `[0, 1]`。
   - 构造分数并列样例时，较小商品位置必须优先。
