# 2026-10-27｜节假日相对日特征与重叠消解

## 1. 任务背景

销量预测中，仅增加“是否节假日”通常不够。节日前备货会提前拉升销量，节日期间每天的节奏不同，节后还可能出现回落。同时，国庆、中秋、会员日等事件窗口可能重叠，如果直接合并，单个日期会产生多行，导致训练样本重复。

今天你将构建一个可复用的节假日特征生成器：

1. 根据每个事件自己的提前天数和滞后天数扩展影响窗口；
2. 计算日期相对事件开始日的有符号距离；
3. 标记节前、节中、节后三种阶段；
4. 在多个事件覆盖同一天时按确定性规则选出主事件；
5. 与完整日历左连接，保证最终每个日期恰好一行。

本练习使用 Pandas 日历表与事件配置，不复用近期的模型训练、时间块置换、序列解码或向量召回套路。预计完成时间：20–30 分钟。

## 4. 待完成任务

1. 实现 `validate_event_config`：
   - 日历必须包含唯一、升序、无缺失的 `date` 列，类型为 datetime。
   - 事件表必须包含题目展示的全部配置列。
   - `event_name` 必须非空且唯一。
   - 开始和结束日期必须为 datetime，且 `start_date <= end_date`。
   - `priority`、`lead_days`、`lag_days` 必须是非负整数。
   - 日历和事件表都不得被原地修改。

2. 实现 `expand_event_candidates`：
   - 每个事件的影响窗口为
     `[start_date - lead_days, end_date + lag_days]`。
   - 只保留落在完整日历范围内的日期。
   - `days_from_start` 使用自然日差，开始日为 0。
   - 日期早于开始日时 `phase="pre"`；位于闭区间 `[start, end]` 时为 `"during"`；晚于结束日时为 `"post"`。
   - `is_in_event` 仅节中为 `True`。
   - `event_day_index` 在节中从 0 递增，节前和节后为 -1。
   - 关键逐事件、逐日期构造逻辑必须由学习者完成。
