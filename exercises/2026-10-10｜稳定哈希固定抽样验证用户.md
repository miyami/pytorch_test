# 2026-10-10｜稳定哈希固定抽样验证用户

## 1. 任务背景

昨天你实现了基于验证集 `Recall@K` 的 LightFM 早停。如果每个 epoch 都随机抽取不同用户，指标波动会同时混入“模型变化”和“样本变化”，早停判断就不再可比。

今天实现一个可复现的验证用户抽样器：

1. 先筛选训练期和验证期交互数都达到要求的用户；
2. 使用“固定种子 + user_id”生成稳定哈希优先级；
3. 选择优先级最小的固定数量用户；
4. 无论程序重启、输入行重排或 epoch 改变，都得到同一批用户；
5. 记录样本签名，便于确认多次实验使用的是同一验证子集。

不要使用 Python 内置的 `hash()`：它可能因解释器进程的哈希随机化而变化。本练习使用标准库 `hashlib`，并且不依赖 LightFM 安装。

预计完成时间：20–30 分钟。

   - 校验 `user_id` 为非空字符串，`seed` 为整数。

4. 实现 `select_fixed_users`：
   - `sample_size` 必须是正整数；两个最小交互阈值必须是非负整数。
