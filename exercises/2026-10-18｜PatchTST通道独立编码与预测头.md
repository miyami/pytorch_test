今天完成一个简化的 PatchTST 编码与预测头：

1. 将商品通道并入批次维，得到 `[B*C, N, D]`；

## 4. 待完成任务

1. 实现 `validate_patch_tokens`：
   - 输入必须是四维浮点 Tensor，布局为 `[B, C, N, D]`。
   - 四个维度都必须大于 0。
   - 所有值必须有限。
   - 不修改输入 Tensor。

2. 实现 `channels_to_batch`：
   - 调用输入校验。
   - 将 `[B, C, N, D]` 转为 `[B*C, N, D]`。
   - 返回转换结果与原始 `(B, C)`。
   - 不允许交换 `N` 和 `D`。
   - 用可读的分步逻辑实现，不写手工循环。

3. 实现 `batch_to_channels`：
   - `forecasts` 必须是二维 Tensor，布局为 `[B*C, H]`。
   - `batch_size` 和 `num_channels` 必须是正整数。
   - 第一维必须严格等于 `batch_size * num_channels`。
   - 先恢复为 `[B, C, H]`，再转换为 `[B, H, C]`。
   - 返回连续内存布局的 Tensor。

4. 实现 `sinusoidal_position_encoding`：
   - `num_positions` 和 `d_model` 必须是正整数。
   - 位置索引 shape 为 `[N, 1]`。
   - 频率项应使用
     `exp(-log(10000) * index / d_model)`。
   - 偶数维填充 `sin`，奇数维填充 `cos`。
   - 返回 shape 必须为 `[1, N, D]`，以便在 `B*C` 维广播。
   - 必须兼容奇数 `d_model`，不能因偶数维数量更多而 shape 报错。

5. 实现 `ChannelIndependentForecaster.forward`：
   - 将通道并入批次后，输入 Transformer 的 shape 必须为 `[B*C, N, D]`。
   - 位置编码的 device 和 dtype 必须与 token 一致。
   - 编码输出沿 `N` 维取均值，得到 `[B*C, D]`。
   - 预测头输出 `[B*C, H]`。
   - 最终输出必须恢复为 `[B, H, C]`。
   - 不在不同商品通道之间做 attention。

6. 用断言完成自检：
   - 合并后的 shape 应为 `(6, 4, 8)`。
   - 恢复后的预测 shape 应为 `(2, 3, 3)`。

   - 位置 0 的偶数维应为 0，奇数维应为 1。
   - `channels_to_batch` 后再按原布局恢复，内容应与原 token 完全一致。
   - 在 `model.eval()` 且关闭梯度时，相同输入重复预测应完全一致。
