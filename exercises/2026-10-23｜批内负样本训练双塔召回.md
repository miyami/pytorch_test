# 2026-10-23｜批内负样本训练双塔召回

## 1. 任务背景

昨天你用 Item2Vec 从商品共现序列中学习商品向量，并显式随机采样负商品。今天进一步构建一个最小双塔召回模型：用户塔编码用户特征，商品塔编码商品特征，同一批次中配对的用户和商品构成正样本，其余商品自动成为负样本。

你需要完成以下训练链路：

1. 分别用用户塔和商品塔生成向量；
2. 对向量做 L2 归一化；
3. 构造批内两两相似度矩阵；
4. 用矩阵对角线表示正样本标签；
5. 同时计算“用户找商品”和“商品找用户”的交叉熵；
6. 在候选商品全集上计算 Recall@K。

本练习使用对齐的用户特征与商品特征，不复用昨天的商品序列、滑动窗口、频次分布或随机负采样。预计完成时间：20–30 分钟。

## 3. 学习目标

完成本练习后，你应该能够：

1. 理解双塔召回中用户塔、商品塔和共享向量空间的作用。
2. 使用 L2 归一化把向量点积转换为余弦相似度。
3. 用矩阵乘法一次生成完整的用户—商品相似度矩阵。
4. 理解批内负样本为何能减少显式负采样开销。
5. 使用温度参数控制分类 logits 的尺度。
6. 实现双向批内交叉熵，并用 Recall@K 评估召回结果。

## 4. 待完成任务

1. 实现 `validate_aligned_batch`：
   - 两个输入都必须是非空二维浮点 Tensor。
   - 两者样本数必须相同，每一行代表一组正样本。
   - 两者必须位于同一 device，所有值必须有限。
   - 不要求用户特征数与商品特征数相同。
   - 不得原地修改输入。

2. 实现 `encode_users` 与 `encode_items`：
   - 输入必须是二维浮点 Tensor。
   - 分别调用正确的塔，不得共享最后一层输出。
   - 使用 `F.normalize(..., p=2, dim=-1)`。
   - 输出每行的 L2 范数应接近 1。
   - 不能使用循环逐行编码。

3. 实现 `TwoTower.forward`：
   - 先调用批次校验函数。
   - 返回用户向量和商品向量。
   - 两个输出的第一维相同，最后一维也相同。
   - 不在 `forward` 内构造标签或计算损失。

4. 实现 `pairwise_logits`：
   - 两个输入必须是二维浮点 Tensor，向量维度相同。
   - `temperature` 必须是有限正数。
   - 使用 `user_embeddings @ item_embeddings.T`。
   - 输出 shape 必须为 `[num_users, num_items]`。
   - 不得用嵌套循环计算相似度。

5. 实现 `bidirectional_in_batch_loss`：
   - 输入必须是非空方阵，因为当前训练批次一一配对。
   - 标签应为 `[0, 1, ..., batch_size - 1]`。
   - 分别计算用户找商品、商品找用户两个方向的交叉熵。
   - 返回有限、非负、保留梯度的零维 Tensor。

6. 实现 `train_one_step`：
   - 严格执行训练模式、清空梯度、前向、构造 logits、计算损失、反向传播和更新参数。
   - `batch_top1_accuracy` 使用用户找商品方向，预测列索引应等于行索引。
   - 返回 `{"loss": ..., "batch_top1_accuracy": ...}`。
   - 两个值都必须转换为 Python `float`。

7. 实现 `recall_at_k`：
   - `logits` 为 `[num_users, num_items]`。
   - 每个用户只有一个目标商品索引。
   - `k` 必须位于 `[1, num_items]`。
   - 用 `torch.topk(..., dim=1)` 召回候选。
   - 返回用户级命中的宏平均 Python `float`。

8. 添加断言完成自检：
   - 模型输出的两个向量 shape 都应为 `[6, 8]`。
   - 每行向量的 L2 范数应接近 1。
   - 训练 logits 应为 `[6, 6]`，对角标签长度为 6。
   - 交换 `temperature=0.15` 与 `0.30` 时，相似度排序不变，但 logits 绝对值应改变。
   - 初始和最终 loss 都必须有限，且至少一个模型参数发生变化。
   - `Recall@1 <= Recall@3`，两个指标都位于 `[0, 1]`。
   - `k=num_items` 时 Recall 必须等于 1。
